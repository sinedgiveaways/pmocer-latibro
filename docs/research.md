# Research

What is known of the game and the hardware, and every source used with its license. The runtime was first written for
another Switch 2 game; its measurements of that game (30/10/2026: the executable, NVN2 against NVN1, the shaders) are
in this file's git history. The sections below hold what was measured on Orbitals.

## The executable (Orbitals)

From `tools/analisis/port_check.py` and `tools/analisis/romfs_check.py` on the player's `.nup` (16/11/2026); the same
numbers are in `recomp/versions.py`.

| Module | Build id (first 8 bytes) | Image |
|---|---|---|
| `main` | `d6efcc0a51c1c792` | 157.8 MiB |
| `sdk` | `daa31832ca979cdf` | 16.4 MiB |
| `subsdk0` | `caf9437bacb2aa16` | 0.8 MiB |
| `rtld` | `f9060b30c6fa2b69` | 0.1 MiB |

- Program ids: `040032B023CA4000` (base, version 65536), `040032B023CA4800` (update, version 327680),
  `040032B023CA5001` (add-on).
- 46 services; 1 305 SDK imports, of which 314 are replaced by the runtime, 991 not, and 319 backed by a console
  service.
- NVN2: 731 procs, 538 implemented, 171 listed and not implemented, 195 names without an implementation.
- Engine: Unreal Engine (`recomp/gen.py`: main+0x4137a50 is reached only through a C++ member-function pointer).
- RomFS: 54 files across the base, the update and the add-on: `Engine/`, `Orbitals/`, `__rom/` and Unreal's manifests;
  1 `.pak` and 4 `.utoc`/`.ucas` containers, 36 `.bk2` movies. No SARC, no BYML, no Gyml archive.

## Switch 2 hardware (T239)

- CPU: 8 × Cortex-A78C (6 for the game), ARMv8.2 + PAC (v8.3/v8.6). ~1 GHz.
- GPU: Ampere, 1 536 CUDA cores (12 SMs, own count), RT and tensor (DLSS). Shaders in SM86 SASS.
- 12 GB LPDDR5X, 102 GB/s.
- Sources: [Switchbrew T239](https://switchbrew.org/wiki/Switch_2:_Tegra_T239),
  [TechSpot](https://www.techspot.com/news/107922-nintendo-finally-clarifies-switch-2-custom-nvidia-processor.html).

Instructions in `main` that a Switch 1 lifter lacks (count from eden-nx2, `NX2_NOTES.md` row "Titles"): RETAA/B
114 767, LDAPR 37 560, LSE atomics 24 718, CAS 6 640, SWP 2 470, CASP 6, XPAC 7, PAC 2, STG 1. PAC is treated as
identity and MTE tags as 0 (eden-nx2, row 3).

## NVN2 against NVN1

Measured on the first game's sdk (30/10/2026; in git history): its NVN2 name table held 699 functions, 529 with the
same name as NVN1's (`totk-pc-recomp/runtime/nvn_procs.inc`), 170 new (DLSS, `ProgramBuilder`, mesh and task draws,
ray tracing, push constants, HDR in `Window*`, variable rate shading). Orbitals' sdk lists 731 (above).

## Shaders

Orbitals' shaders are not in agl/BNSH archives, so the setup's shader step is skipped for it (`recomp/versions.py`
`skip_steps`). Where its programs sit in the `.pak`/`.utoc` containers, and how they reach NVN2, is still to find.
Until then a run dumps every program it meets without SPIR-V and the player translates them; see
[shaders.md](shaders.md).
